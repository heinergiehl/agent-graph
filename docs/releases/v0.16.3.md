# AgentGraph v0.16.3

Status: **Stable pre-v1 patch release**. Release date: 2026-09-05.

AgentGraph 0.16.3 fixes durable context loss, unsafe resume acceptance, and false completion when Laravel AI requires native tool approval. The Laravel AI baseline remains `^0.11.2`. No public method signature, persistence adapter contract, or database migration changes in this patch.

## Corrections

- Waiting runs require a matching non-empty string interrupt ID. Expiry is checked during acceptance, and omitting the ID cannot replace an already accepted answer or bypass an expired wait.
- Recovery preserves the full saved Send schedule, including duplicate destinations, local input, and metadata. An empty terminal continuation completes without rerunning entry nodes. Unbound state patches are rejected.
- Synchronous and queued interrupt checkpoints retain the active Send invocation for ordinary and state-edit resumes. A mismatched checkpoint continuation is rejected before accepting an answer.
- Prompt and streamed native Laravel AI approvals fail with `AgentApprovalRequiredException`. No partial node writes are committed, downstream nodes do not run, and automatic retries do not repeat the model call. `AgentNode` does not implement native approval resumption; authorize work through graph approval interrupts or an application-owned node.
- Database memory writes return their saved receipt even when the record has expired, without incrementing usage or emitting a read event. Expired records remain excluded from retrieval.

## Upgrade

```bash
composer require heiner/agent-graph:^0.16.3 --with-all-dependencies
```

Restart long-lived application processes together after updating the lock. The Filament Agentic Chatbot release must pin exact `0.16.3` and pass its own integration and immutable-lock gates.

Existing checkpoints remain readable. Send context already discarded by an older wait checkpoint cannot be reconstructed automatically; reconcile affected waits from trusted application records. Previously emitted streaming deltas remain provisional until the final run outcome is known. External side effects still require application idempotency and reconciliation for unknown outcomes.
