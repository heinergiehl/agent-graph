# AgentGraph v0.14.0 Release Notes

Released: 2026-06-17

## Summary

AgentGraph v0.14.0 adds the runtime contract and release-readiness APIs needed for safer Laravel AI workflow products:

- Typed interrupt contracts for stable human-in-the-loop projections.
- Graph manifests for read-only metadata, inspectors, visual editors, and release checks.
- Graph validation reports and the `agent-graph:validate` command for CI and deployment gates.
- Better graph-as-tool schemas, including explicit `GraphTool::schemaInput()` for bounded public tool input.
- Composer security audit coverage in the package `check` script.

## Compatibility

This release is additive over the 0.13 runtime surface. Existing applications pinned to `heiner/agent-graph:^0.13.0` remain on the 0.13 line and will not install v0.14.0 automatically.

Applications should opt in by changing their Composer constraint to `^0.14.0`, then running their graph, interrupt/resume, and Laravel AI tool integration tests.

## Release Verification

The release commit was verified with:

```bash
composer check
```

Expected coverage includes Pint, Pest, PHPStan, and `composer audit --no-dev`. The optional pgvector integration test remains skipped unless `AGENT_GRAPH_PGVECTOR_TESTS` is explicitly enabled.
