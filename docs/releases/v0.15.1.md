# AgentGraph v0.15.1

Release date: 2026-07-12

## Summary

AgentGraph v0.15.1 hardens the stable 0.15 runtime line around process loss and duplicate delivery:

- Resume and state-edit acceptance are committed atomically with a bounded recovery marker.
- `AgentGraph::recover($runId)` continues accepted resume transitions or running runs from their latest durable checkpoint.
- Cancel resolves a pending interrupt atomically with the terminal run transition.
- Queued-superstep frontiers are committed before dispatch and can be redriven after post-commit dispatch loss.

## Compatibility

This release is additive and requires no migration. Existing 0.15 graph definitions and persisted runs remain compatible.

Applications that performed their own best-effort pending-interrupt cleanup after `cancel()` must remove that duplicate cleanup. AgentGraph v0.15.1 owns interrupt finalization as part of the atomic cancel transition.

Recovery does not promise exactly-once execution for arbitrary PHP node callbacks. A synchronous frontier that did not reach its next durable checkpoint can execute again. Keep external side effects inside `TaskRunner::once()` and use provider idempotency where available.

## Upgrade

```bash
composer require heiner/agent-graph:^0.15.1 --with-all-dependencies
php artisan agent-graph:doctor
```

Run the host application's interrupt/resume, cancellation, queue-worker, and recovery tests after updating.
