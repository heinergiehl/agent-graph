# AgentGraph v0.16.2

Status: **Stable pre-v1 patch release**. Release date: 2026-09-04.

AgentGraph 0.16.2 keeps the complete 0.16.1 runtime and migration behavior while raising the supported Laravel AI baseline to `^0.11.2`. No graph execution behavior, public runtime method, persistence contract, graph artifact, or database migration changes in this patch.

## Why this patch is required

Laravel AI 0.9 moved provider tool execution into a shared multi-step generation loop. Laravel AI 0.10.3 added explicit Gemini coverage for preserving thought signatures across tool-call continuations. The Filament Agentic Chatbot's Gemini 2.5 Flash-Lite release test requires that corrected provider loop, but AgentGraph 0.16.1 constrained Composer to the older 0.7 line.

This patch changes the dependency to `laravel/ai:^0.11.2`. Compatibility fixtures now implement the SDK's widened `Decisions|string` Agent prompt signatures introduced in 0.10. AgentGraph itself continues to depend only on Laravel AI public contracts, response objects, tools, and streaming events.

## Upgrade

```bash
composer require heiner/agent-graph:^0.16.2 laravel/ai:^0.11.2 --with-all-dependencies
```

Applications implementing `Laravel\Ai\Contracts\Agent` directly must accept `Laravel\Ai\Approvals\Decisions|string` for prompt parameters. Agents using Laravel AI's `Promptable` trait already receive compatible methods. Keep workers stopped during the lock update and restart every web, queue, and scheduler process on the same dependency set.

The Filament Agentic Chatbot commercial release must pin exact AgentGraph `0.16.2` rather than a caret range.

## Verification

- Composer manifest validation passed against Laravel AI 0.11.2.
- The complete SDK suite passed: 357 tests and 2,633 assertions. The two existing opt-in external PostgreSQL and pgvector tests remained explicitly skipped locally.
- PHPStan, Pint, the production dependency audit, and the GitHub PHP 8.3/8.4 by Laravel 12/13 matrix are release gates for the exact tag commit.

All 0.16.1 migration guarantees and 0.16.0 runtime limits remain in force. See the [upgrade guide](../../UPGRADE.md) and [0.16.1 release notes](v0.16.1.md).
