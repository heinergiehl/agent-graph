# AgentGraph 0.18.0

This SDK release removes recursive synchronous execution and separates node invocation and resume validation from durable graph coordination. Laravel AI remains responsible for agents, providers, streaming responses and its native tool loop.

## Runtime responsibilities

| Class | Responsibility |
| --- | --- |
| `GraphRuntime` | Accept run controls, schedule receipts, commit checkpoints and drive the graph. |
| `ExecutionFrontier` | Carry a committed receipt schedule and its expected run revision to delivery. |
| `NodeExecutor` | Resolve and invoke a node, create its context, apply retry/concurrency policy and share its deadline. |
| `ExecutionAuthority` | Check a fixed run revision, ancestor status, receipt claim and optional monotonic deadline. Never adopt a newer owner. |
| `ResumeProtocol` | Validate interrupt identities, response bindings, subgraph waits and durable recovery proof without writing state. |

The old implementations are removed from `GraphRuntime`. Run arrays no longer carry hidden `_execution_id`, `_claim_token` or `_deadline` fields. Persisted schemas and receipt formats remain unchanged.

Initial scheduling and resume acceptance use short coordination locks. Node invocations occur after those locks are released; checkpoint commits reacquire the run lock and retain revision fencing. A session lock serializes run selection/creation, not an entire model invocation. Explicit node concurrency locks still cover the node. Synchronous delivery advances in a loop; queued delivery uses the same persisted receipts and returns current state even when the configured queue driver executes immediately.

## Evidence

- An 80-step synchronous graph previously added 316 PHP stack frames. The regression test now requires stack-depth variation below five frames, independent of step count.
- A synthetic burst of 500 native text deltas previously required 515 run-store reads. It now stays below 50 in the local test. Text bursts poll ownership at 50 ms intervals; every non-text event and final result still checks authority. A cancellation test verifies that the next control event stops consumption and prevents committed partial output. These are deterministic fake-stream tests, not production latency benchmarks.
- The full local suite passed **435 tests / 3,005 assertions**, including all PostgreSQL/pgvector opt-ins without skips, on PHP 8.4.4, Laravel 13.31.0 and Laravel AI 0.11.2. PostgreSQL tests use independent worker processes for cancellation, expired-lease replacement, killed-worker recovery and simultaneous resume acceptance.
- Strict Composer validation, PHPStan, Pint and the production dependency audit passed. The release workflow additionally checks the PHP 8.3/8.4 × Laravel 12/13 CI matrix and an installed Laravel sandbox before publication.

The coordinator is about 400 lines smaller. Total production PHP remains slightly larger because explicit ownership/frontier types replace implicit fields and the lock/delivery split adds real boundaries. The purpose is simpler responsibilities and verified behavior, not a misleading line-count target.

## Upgrade

```bash
composer require heiner/agent-graph:^0.18.0 --with-all-dependencies
php artisan agent-graph:doctor
```

Stop and restart all graph-executing processes together. There is no new 0.18 migration; installations upgrading from before 0.17 must also apply the [0.17 migrations](v0.17.0.md#upgrade). Read the [internal subclass migration notes](../../UPGRADE.md#0170-to-0180-runtime-responsibilities-and-short-coordination-locks) before upgrading custom `GraphRuntime` subclasses. Exact consuming-plugin pins must be changed explicitly and verified by the plugin's own integration tests.

## Limits

Cancellation is cooperative and cannot undo an already admitted external request. Native Laravel AI inner tool calls are not separately checkpointed or authorized by this SDK. Applications remain responsible for tenant/user authorization, effect idempotency and reconciliation after ambiguous provider outcomes. Native tool-approval resumption and parallel graph interrupts retain their documented limitations. No plugin code or paid model calls are included in this SDK release.
